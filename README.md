## Purpose

This repository provides a safe sandbox for experimenting with Git operations
such as branching, rebasing, merging, and commit history manipulation.

## Getting Started

Clone the repository to begin experimenting:

```bash
git clone https://github.com/sonarsource/git-demo.git
cd git-demo
```

## Usage

Create a new branch, make some changes, and practice your Git workflow:

```bash
git checkout -b my-experiment
```

## Features

This repository is used to demonstrate the following Git and GitHub features.

- Branching and merging strategies
- Rebasing and history rewriting
- Pull request review workflows
- Conflict resolution scenarios
